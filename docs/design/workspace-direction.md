Mode: Operate. Whole-workspace redesign, confirmed by the user. Build directly in code; no raster assets are required.

## Direction contract
THESIS: An invoice board with the density and scanability of a stock-market board. The user rejected the earlier summary-led dashboard; the ledger is now the primary surface.

OWN-WORLD: Collex replaces Greenbar at the user's request. The Apple reference supplies restrained chrome, cool gray and white surfaces, graphite text and system sans. The subsequent stock-market-board reference supplies compact rows, aligned tabular numbers, column sorting and semantic red/green. No invented price movement, pulsing decoration, large icon tiles or chart filler on the board. The subsequent user-requested cute plush character belongs only in the Ask panel.

STORY: Scan all invoices, filter status or owner, search across the complete export, sort balances or age, page results, then open the invoice with its evidence and existing approval controls. Ask a question when needed.

FIRST VIEWPORT: Compact horizontal navigation; Invoice board heading and dated snapshot; a narrow portfolio totals strip; status filters and search; a broad table with sticky sortable columns. At narrow widths, the ledger scrolls within its own region. Every invoice is reachable through server pagination, without truncating the export. Detail views retain context and review controls. A keyboard-dismissible 360px chat sidebar opens beside the ledger by default on desktop (1200px and above); on smaller screens it remains collapsible. The plush character is the agent face in navigation, chat header, welcome and replies.

FORM: User-pinned Apple-inspired product interface overrides randomized visual-world selection; seed:0109a36ddcd8bc50. Conventional navigation and controls support frequent collection tasks in a normally lit office.
